# Architecture Decisions

현재 구조는 `docs/architecture.md`, **왜 그렇게 했는지**는 여기 ADR에 둔다.

## Naming

`NNN-short-title.md` (예: `001-use-postgresql.md`)

## Template

```md
# ADR-NNN: Title

## Status

Proposed | Accepted | Superseded

## Context

왜 결정이 필요했는가.

## Decision

무엇을 선택했는가.

## Alternatives

고려했지만 선택하지 않은 옵션.

## Consequences

이점·제약·후속 작업.
```

결정이 생기기 전에는 이 README만 유지한다. 추측으로 ADR을 대량 생성하지 않는다.
